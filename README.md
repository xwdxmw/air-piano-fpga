# Air Piano — 基于 FPGA 的实时多音色合成电子乐器引擎

纯 Verilog HDL 实现的实时多音色电子乐器，**32 个独立发声音槽并行合成**，内置钟琴、笛子、红外竖琴三种音色，支持力度、弯音、颤音三维演奏表情与回声效果器，搭配 ST7735 显示屏与 30 颗 WS2812 演奏指引。全链路无 MCU、无软核 CPU、无预录 PCM 采样，所有声音均由 DDS 振荡器逐样本实时生成。

- **目标器件**：高云 GW5AST-LV138FPG676AC1/I0（Sipeed Tang Mega 138K Pro，GW5AST-138）
- **开发工具**：Gowin 云源软件 V1.9.12
- **代码规模**：73 个 Verilog 文件共 9,262 行（53 个功能模块 7,051 行 + 20 个 testbench 2,211 行）

---

## 一、功能特性

| 类别 | 功能 | 实现方式 |
|---|---|---|
| 多音色 | 钟琴、笛子、红外竖琴三种音色 | `bell_bank` / `flute_bank` / 整流正弦 `wave_harp`，各配独立 ADSR 参数 |
| 复音 | 32 个独立音槽同时发声 | `generate` 并行例化 32 个 `voice`，非时分复用 |
| 演奏表情 | 力度、弯音、颤音三维 | FSR 力度映射、弯音频率比例 ROM（约 ±2 半音）、5.3 Hz LFO 颤音 |
| 效果器 | 回声（Echo） | 块 RAM 延迟线，延迟约 150 ms、反馈系数 0.5 |
| 音频输出 | 板载 PT8211 DAC + 3.5 mm 接口 | 免配置、无 I2C、无 MCLK，直接接有源音箱 AUX |
| 显示 | ST7735 160×128 屏幕 | 李萨如波形、活跃音槽、频谱与模式状态 |
| 灯光指引 | 30 颗 WS2812 | 前 8 颗按键提示，《小星星》脱机演奏指引 |
| 运行模式 | 正常 N / 指引 G / 32 音诊断 T | 上电选择与手势切换 |

## 二、系统架构

系统分为两个时钟域：50 MHz 控制域负责传感器采集、手势识别与事件调度；12.264 MHz 音频域负责 32 音槽合成、混音、效果与音频发送。两域之间通过 4-phase 握手总线与双触发器同步器传递事件，约束文件对全部跨时钟域路径设置 `set_false_path`。

```
┌──────────────────────── top_system（50 MHz 控制域）────────────────────────┐
│  boot_select（上电模式选择）                                               │
│  c_sync_debounce + ttp_gestures（触摸消抖/手势）                          │
│  performance_controls（S1 音色 / S2 弯音）                                 │
│  ads1256_driver（8 路 FSR，SPI）→ c_interact_top（交互生成事件）           │
│  note_transpose（实时变调/八度）  guide_seq（脱机指引）                    │
│                              │ 8 路事件汇入                                │
│                              ▼                                             │
│                   event_queue_multi（DW 19，DEPTH 64）                     │
│                              │ 4-phase 握手                                │
└──────────────────────────────┼─────────────────────────────────────────────┘
                                │ event payload 19 bit（2FF 跨域同步）
┌──────────────────────── top_board（12.264 MHz 音频域）─────────────────────┐
│  top_synth：note_freq_rom（共享）+ poly_mgr + voice_array（32× voice）     │
│      每个 voice：DDS 振荡器 + 多音色波形 + ADSR 包络                       │
│  mixer（按活跃声部动态增益）→ delay_fx（回声）→ pt8211_tx                  │
│  lcd_panel（显示）   ws2812_tx（30 颗灯）                                  │
└──────────────────────────────┼─────────────────────────────────────────────┘
                                │ BCLK / WS / DACDATA
                                ▼
                    板载 PT8211 → 3.5 mm → 有源音箱
```

**事件 payload（19 bit）**：`[18:17]` 来源 owner（钢琴 0 / 竖琴 1 / 演示·测试 2 / 指引 3）、`[16]` 音色 timbre、`[15:14]` 类型（NOTE_ON / NOTE_OFF / ALL_NOTES_OFF / 预留）、`[13:7]` 音符编号 0–127、`[6:0]` 力度 0–127。NOTE_ON 时锁存该音音色，后续尾音不随模式切换而改变。

## 六、演奏操作

| 操作 | 效果 |
|---|---|
| S0 | 复位：默认钟琴、八度 0、颤音关 |
| S1 | 钟琴 ↔ 笛子切换（仅影响新触发的压力音，红外竖琴不跟随） |
| S2 按住 / 松开 | 平滑弯音约 +2 半音 / 回到原调 |
| TTP 单击 | 颤音开 / 关（约 300 ms 确认窗） |
| TTP 300 ms 内双击 | 升八度（上限 +2） |
| TTP 按住 0.7–3 s 后松开 | 降八度（下限 −2） |
| TTP 长按 ≥3 s 后松开 | 进入 / 退出《小星星》指引模式 G |
| 组合按键约 3 s | 进入 32 音诊断模式 T |

诊断模式 T 每 200 ms 叠加一个声部，约 6.4 s 完成 32 音加载，满载保持至少 10 s，释放后留 3 s 空档。

## 七、构建与复现

1. 安装 Gowin 云源软件（V1.9.12 或兼容版本）。
2. 新建工程，目标器件选择 `GW5AST-LV138FPG676AC1/I0`。
3. 添加 `src/` 下全部 `.v` 文件（含 `src/gowin_pll/` 两个 PLL 文件）。
4. 导入引脚约束 `src/pin_airpiano_138k.cst` 与时序约束 `src/clk.sdc`。
5. 依次运行综合（Synthesis）、布局布线（Place & Route）、生成比特流（Bitstream）。
6. 使用 Gowin Programmer 烧录。

> 工程路径请使用纯英文，含中文路径会导致 Gowin 报 SP0002 Corrupted project file。

## 八、验证方式与边界

- `src/` 内含 20 个 testbench（`tb_*.v`），覆盖按键力度、键屏蔽、压力时序、光电竖琴、触摸手势、模式切换、事件队列、复音管理、PT8211 时序、效果器 LFO 等。
- 共完成 **60 项回归测试与 20 组复位场景**，结果全部通过。
- 验证依据为 RTL 仿真与实际布局布线报告（资源、时序、可烧录性）。**当前版本尚未进行实板启动与实测延迟测量**，屏幕与灯光的物理呈现以仿真和布局布线证据为准，不夸大为上板结论。
