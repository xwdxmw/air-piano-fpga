# AP04 接线核对

保持 AP04 已工作硬件连接。以下为 **FPGA 球位**，不等同于连接器物理针号；原封存手册中部分物理针号存在不一致，本整理不继续传播未经重新核实的排针编号。请按实际底板版本原理图定位，不能套用通用 PMOD 供电针序。

| 外设 | 信号与 FPGA 球位 |
|---|---|
| ADS1256 | SCLK A18 / DIN A17 / DOUT A19 / CS B19 / DRDY A20 / RESET B20 |
| TTP223 | OUT B21，点动模式 |
| WS2812B | DIN C21，30 颗，确认 DIN 方向 |
| IR1–IR8 | H15 / H14 / L18 / L17 / D25 / E25 / B24 / C24 |
| 屏幕 | SCLK T24 / MOSI R17 / CS L24 / DC N18 |
| 板载按键 | S0 K16 复位 / S1 G15 音色 / S2 F15 弯音 |
| 板载 PT8211 | BCLK E22 / WS F24 / DATA G24，板内连接 |

FSR 分压、ADS1256 模块、FPGA 及其他外设必须有正确公共参考地。ADS1256 的 AINCOM 如未引出，应按实际模块原理图核对其参考，不能凭模块端子数量臆测内部接法。模拟电源与 FPGA 数字 IO 的 3.3V 兼容性分别核实，禁止把 5V 信号直接接入 FPGA。

灯带使用足够的 5V 供电和适当的数据电平缓冲，电源负端共地，避免灯带大电流经过 FSR 参考地。当前仍有实物不亮反馈，RTL 通过不代表接线和电平已确认。

屏幕按横向 160×128、ST7735 配置，实际采购屏 IC 尚无型号证明；保持已工作 RES/BL 接法。卖家给过的其他尺寸参数不能作为这块 1.8 寸屏的型号证据。

音频从开发板原 3.5mm 口接有源音箱 AUX 或适配的线路输入。主线不需要 UDA1334A、PCM5102 或新增时钟跳线。
