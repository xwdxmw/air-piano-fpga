# AP04：保留AP03功能的资源与时序优化

AP03原目录、固件和ZIP保留。本版继续使用138K Pro及原接线，屏幕右上改为AP04；N/G/T、32声部、钟琴/笛子/红外竖琴、所有手势、回声、屏幕和灯带功能沿用AP03。

## 优化了什么

|改动|原因|功能保持的依据|
|---|---|---|
|32个声部共用一个音符频率ROM，分配音槽时锁存频率字|减少重复音符查表及块RAM|保留32个完整独立合成声部；查表发生在同一个事件分配时刻，不增加音频采样等待。与AP03参考引擎逐位比较PCM、活跃掩码和包络状态|
|LCD缓存本帧声部数字字形；版本字符直接选择常量字形|AP03的50MHz最差路径来自LCD坐标到像素数据，余量0.215ns|帧状态仍先快照；字形缓存早于第4行显示区域准备完成。像素颜色、布局和帧协议对照检查；只有版本标识改成AP04|
|LCD频谱柱索引改用固定区间译码和移位相减|避免每像素做除10和取余的长组合运算|在实际使用的x=2..157范围逐坐标核对商和余数|
|LCD字形行偏移增加一级缓存|拆开行坐标计算与字形选位的组合链|实际光栅扫描在第4列后才绘制字形，缓存此前已准备；逐像素与完整SPI帧对照保持|
|事件队列按请求前缀计数计算入队位置和可接收数|缩短8条事件逐级检查队满的反馈链；AP03也有此处紧路径|不增加事件延迟、不改事件顺序；在2/4/8条输入、不同深度上与AP03逐拍核对队满、同拍出入、回绕、溢出和复位|
|WS2812改为当前字移位发送|消除大位宽变量选位反馈，第一轮新布局曾在这里出现Setup违例|与AP03逐时钟比较1/8/30颗配置，每组299999个时钟；动态输入快照、中途复位及实际高低脉宽都保持|
|ADC与FSR两处计时器按最大计数值选择位宽|减少不需要的高位寄存器和进位链|所有原比较值、计数步进和等待长度保持。ADC真实引脚行为模型核对SPI保持时间、DRDY、通道顺序和扫描周期；压力路径另测|

共享的是**音符到基础频率的控制查表**。钟琴、笛子、竖琴的不同音色算法/波表仍分别保留；32声部的相位、包络及音频运算仍独立并行。

## 这轮保留的边界

- ADC协议、30kSPS配置、FSR触发阈值和2.7ms力度补偿窗沿用AP03。扫描模型仍应为2.170420ms一轮；本版不宣称进一步降低AIN到3.5mm的实测延迟。
- T模式仍每200ms叠加一音，6.4秒加载、满载另保持10秒、释放留3秒；32音目标频率和音频采样率保持。
- N模式FSR紫色/IR青色/同路白色，释放约80ms保持；前8灯提示，第9～30颗清黑。G指引、T自检后灯带熄灭的规则保持。
- 引脚约束、时钟约束、PLL IP及专用脚复用选项沿用AP03。没有新增false-path、多周期约束或通过关闭警告制造时序通过。

## 验证与尚未闭合的事项

最终构建结果以`reports/reference/AP04_release_status.json`及原 AP04 封存材料为准。完整回归覆盖交互、音色、32声部、频谱/波形/音槽、灯带、SPI、混音、回声及复位；新增AP03参考实现参与音频/像素/事件队列对照。

这些是代码、仿真和布局布线证据，不等同于实机长期运行或Flash冷启动测试。PR1014若仍被工具报告，则仍未闭合；板载P16时钟来源、外设供电、屏幕SSPI复用与实际断电启动应按上板流程确认。本版不加入全局故障自锁静音。

第一轮构建因一条WS2812路径Setup违例而被交付检查拒绝，未复制到烧录目录、未打包为可用固件。原报告保留于`reports/attempt01`。该目录只是审阅记录；最终可烧录文件只认本包`fs`目录及交付状态中的哈希。

第二轮完成固件、时序及资源报告后，Gowin退出进程挂起，CPU计数在两次相隔较长时间的检查中不变。保存输入/输出哈希并确认生成完成后结束该进程，真实退出码−1保留，未改写为0。最终交付独立复核原生输出完整、文件未变化、时序0/0及完整回归通过；诊断记录见`reports/GOWIN_EXIT_HANG.json`。此为构建工具退出异常，不是实板运行或冷启动测试结果。
