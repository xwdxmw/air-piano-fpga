## 操作

| 操作 | 结果 |
|---|---|
| 释放 FSR/TTP，红外通光，按松 S0，等约 4 秒 | N 普通演奏，钟琴、八度 0、颤音关 |
| S2 按松 | 新触发压力音在钟琴／笛子之间切换，红外竖琴不变 |
| S1 按住／松开 | 压力音平滑弯高约 2 半音／恢复 |
| TTP 单击 | 约 300ms 确认后切换颤音 |
| TTP 约 300ms 内双击 | 升八度，最多 +2 |
| TTP 按住 0.7～<3 秒后释放 | 降八度，最低 -2 |
| N 中 TTP 按住 ≥3 秒后释放 | 进／出小星星 G；也可释放 TTP 后 S0 回 N |
| 先释放 TTP ≥1 秒，再按住 TTP 短按 S0；释放 S0 后继续持 TTP 约 1 秒再松开 | 约 3 秒进入 32 声部 T，不要持到 3 秒；释放 TTP 后 S0 回 N |

T 模式每 200ms 加一音，约 6.4 秒加载 32 音，保持约 10 秒，释放留 3 秒空档循环。从释放 S0 起约 9～10 秒首次出现 V32/32。T 模式忽略普通 S1/S2/TTP 操作；开机自检之后灯带黑是设计预期。

## 必测顺序与预期

1. **版本、静音和复位**：确认 AP04/N；无人操作时不应幽灵起音。反复复位后不应有旧回声、卡音或长时间失声。
2. **八路压力与八路红外**：逐路按松／遮挡，核对音高、释放、对应显示，再混合快奏。N 模式前八灯预期 FSR 紫、IR 青、同路同时白，释放保留约 80ms；第 9–30 灯黑。灯不亮需单独记录，不能因有声音就判灯带通过。
3. **复音、音色与表情**：至少四音同按并逐一释放；钟琴、笛子、竖琴分别录音；笛子长按后释放测 ADSR，钟琴和竖琴检查自然衰减；测力度、弯音、颤音及八度边界。
4. **回声和屏幕**：单音检查约 150ms 回声重复及复位清历史；横屏图像、模式、音槽数稳定，波形来自最终 PCM；16 频点显示不能代替 32 峰验收。
5. **G 指引**：完整小星星演示，核对目标音、重复音间隙、提示灯及按对反馈，退出后恢复 N。
6. **T 满载**：至少三轮，同时拍 V32/32 与 32 格，并用线路输入录原始 WAV。按 target_frequencies.csv 核对峰，保存满载中段和失败窗口；不能只凭声音密集就判 32 声部。
7. **延迟**：压力 AIN／数字事件／模拟音频分段测量；记录起点阈值、终点阈值、音色、采样通道、时基及多次分布。1ms/格与2ms/格观测曾不一致，保留两组原始记录；不能由少数 <5ms 截图推出最坏延迟 ≤5ms 或无抖动。
8. **可靠性**：Flash 断电启动 20 次（SRAM 下载不算），随后连续 1～2 小时混合 N/G/T。记录失声、重启、卡音、花屏及灯带异常。原 20 组复位仿真不能代替本项。

若出现回归，回到原封存固件并保持相同接线。本次只整理仓库，不改 AP04 逻辑，也没有生成 GAO 专用固件；外部示波器／逻辑分析仪可测实际引出信号，内部 GAO 探针需另建调试版本并重新实现。
